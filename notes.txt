Class - 1

    -> What Is DevOps ? 

        -> DevOps Is a Set Of "PRACTICES" that works To 
        "AUTOMATE" and "INTEGRATE" the process between 
        Software Development(Dev) and IT Operations(Ops) Teams.

    
    -> Development(Dev) Team

        -> To "Build Applications", We Need Roles Like 

            -> Software Architects 
            -> Software Developers 
            -> Software Testers 
            -> etc 

    -> IT Operations(Ops) Team

        -> To "Build Infrastructure" & "Deploy Applications" We Need Roles Like 

            -> System Admin 
            -> Network Admins 
            -> Cloud Admins 
            -> Build & Release Engineers 

    
    -> DevOps Engineer 

        -> DevOps Engineer Will Implement DevOps "PRACTICES" Using "TOOLS"
        So that organizations can Build, Test and Deploy Softwares 
        More "FASTER" & "RELIABLE".

        -> NOTE: Simple Comparison, Web Browsing is a practice which is done using Tools 
        Like Chrome, Edge, Firefox, Safari etc.


    -> DevOps PRACTICES                                 -> DevOps TOOLS 

        -> Version Control System (VCS)                     -> Git 

            -> For Tracking Code 

            -> Code is Written in Developer Laptop (Tracking) - Individual Developer 


        -> Source Code Management (SCM)                     -> GitHub 

            -> Storing Multiple Versions Of Code 

            -> Happens At organization Level - Centralized For All Developers 

        
        -> Containerization                                 -> Docker 

            -> For Getting Acceleration i.e Making "FASTER" 

        
        -> Orchestration                                    -> Kubernetes 

            -> For Getting Reliability 

            -> Reliable Means Running Applications Without Downtime (Run 24 X 7)

        -> CI / CD                                          -> Jenkins

==========

    -> Servers 

        ->  A Server is a "computer system" that provides data or services 
        to others computers, known as "clients" over a network.

        -> https://upload.wikimedia.org/wikipedia/commons/c/c9/Client-server-model.svg

    -> Computer / Laptop Can Be Used By Only One Person At a Time 

    -> Server Can Be Used By Multiple Persons (Clients) At a Time 

    -> Physical Server 

        -> Physical Server is hosted on Physical Datacenter / On-prem Datacenter

    -> Virtual Server / Cloud Server 

        -> Virtual Server / Cloud Server is hosted on Virtual Datacenter / Cloud Datacenter 

    -> NOTE: Any Type Of Server has Components i.e Physical / Virtual / Cloud 

        -> CPU (processor) + RAM (memory) + HDD (Disk) + Network 

        -> Operating System (Linux OS - Ubuntu)

        -> Server Softwares 

            -> Web Server: Hosts Web Pages / Web Applications Over Internet 

                -> Examples: Apache Web Server, Nginx Web Server, IIS Server etc 

            -> Database Server: Hosts Application Data & Transactions 

                -> Examples: MySQL Server, Postgres Server, Oracle DB Server etc 

            -> Email Server: Hosts Email Services, To Send and Receive Emails 

                -> Examples: Postfix Server, SendMail, SendGrid etc

        -> Check Running Processes 

            -> ps -ef 

            -> htop (type q to quit)

    
    -> Web Server 

        -> A Web Server Is Computer Software which Accepts Request via HTTP 
        Over Port 80 To Distribute Web Content.

        -> NOTE: All Servers That Host Websites Must Have "Web Server" Program

        -> NOTE: Whole Internet Is Powered Web Servers 

        -> Commands To Work With Web Server 

            -> sudo ss -ntpl 

            -> We can see ports 22 & 53, which are already installed as part OS 

            -> We Don't See Port 80 Which Indicates there is no web server software 

        -> Install Web Server (Nginx)

            -> sudo apt update -y 

            -> sudo apt install nginx -y 

            -> sudo ss -ntpl 

                -> We Should See Port 80 Which Indicates web server software is present

            -> Browse http://ip-address-server 

                -> If you see this page, the nginx web server is successfully installed 
                and working. Further configuration is required.
